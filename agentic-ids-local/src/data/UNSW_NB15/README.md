# UNSW-NB15 Dataset

## Overview
The UNSW-NB15 dataset is a comprehensive network traffic dataset designed for evaluating network intrusion detection systems. It contains a hybrid of real modern normal activities and synthetic contemporary attack behaviors.

## Dataset Details
- **Features**: 49 features extracted from raw network packets.
- **Labels**: Binary classification (normal/attack) and multi-class classification (attack types).
- **Size**: Approximately 2.5 million records.
- **Format**: CSV files.

## Download
The dataset can be downloaded from the official UNSW research page: [UNSW-NB15 Dataset](https://research.unsw.edu.au/projects/unsw-nb15-dataset).

### Files Available for Download:
- `UNSW_NB15_training-set.csv` - Training set (82332 records).
- `UNSW_NB15_testing-set.csv` - Testing set (175341 records).
- `NUSW-NB15_features.csv` - Feature descriptions.
- `NUSW-NB15_1.csv` 
- `NUSW-NB15_2.csv` 

- Additional files may include raw PCAP captures and other variants.

To download, visit the link above and follow the instructions provided on the page. Note that some files may require registration or specific access.

## Usage
This dataset is intended for research purposes in cybersecurity, particularly for machine learning-based intrusion detection.

For more details, refer to the original publication: Moustafa, Nour, and Jill Slay. "UNSW-NB15: a comprehensive data set for network intrusion detection systems (UNSW-NB15 network data set)." Military Communications and Information Systems Conference (MilCIS), 2015.
